# Design amendments v0.2 — TLM_MQ01 and TLM_SQ01

**Status:** PROPOSED, 2026-11-11. Awaiting owner review. Nothing here has been run in Fallout 4.
**Applies to:** [TLM_MQ01 — Six Rounds to Mercy](TLM_MQ01_six-rounds-to-mercy.md) and [TLM_SQ01 — Signed Clean](TLM_SQ01_signed-clean.md), both v0.1.
Where this document and a v0.1 design disagree, this document is what the model, the scripts and the plugin builder implement.

## How these were found

The v0.1 stage tables were turned into an executable model ([tools/logic_model](../../tools/logic_model/)) and every reachable state was searched. The model is not the game: it checks that the rules are consistent with each other, and nothing about AI, timing or presentation.

| Rule set | Reachable states | Invariant violations | States that cannot finish MQ01 |
|---|---|---|---|
| v0.1 as written | 45,873 | 9 kinds, each addressed by an amendment below | 8,736 |
| v0.2 (this document) | 16,515 (MQ01) + 5,185 (SQ01) | 0 | 0 |

Where v0.1 was ambiguous the model takes the literal reading, so the v0.1 row is a measure of what the text allows, not of what was intended.

The shortest v0.1 soft-lock: start, take the dispatch, walk to town, hand it over, walk away before Pritchard finishes. No greeting in v0.1 fits "stage 50 done, no dispatch in hand", so the hand-off could never be reached again.

A second group of amendments came from the Creation Kit wiki ([VERIFY_LOG.md](VERIFY_LOG.md)), mainly that alias scripts only run while their quest is running and that a stage fires once.

## MQ01 amendments

| ID | v0.1 said | Problem | v0.2 |
|---|---|---|---|
| **A1** | Cutters are killable by anyone. Any Cutter-lead death resolves **Saved**. | The caravan hands can kill Dunmore on their own. The player then gets "saved", the reputation and the trust for watching. | Cutter aliases are **Protected** until the encounter resolves, so only the player can kill them. |
| **A2** | The evade timer resolves **Evaded** when it expires. | It fires in the middle of a fight the player is winning (T14). | The timer never resolves while the player is in combat; it re-arms. Leaving the area (distance event) always resolves Evaded. T14 is split into three cases. |
| **A3** | "First resolution wins. Later events are ignored." | Save the caravan, then shoot Nell: Pritchard still says "Obliged" and reputation is +2. | The player killing a caravan hand **before the debrief** always converts the outcome to Exploited / Betrayal. It gets its own **stage 35**; stage 33 is the deal only. |
| **A4** | No rule for an encounter the player never resolves. | Reaching stage 50 with outcome 0: Pritchard has no line, and the caravan fight never ends. 720 such states. | At the town gate an unresolved encounter is resolved: never met → new outcome **4 Missed** (stage 34, no accusation, no player choice); walked away mid-fight → Evaded. |
| **A5** | Pritchard greeting A needs the dispatch; B needs stage < 20. | After the hand-over neither fits. Walking away between P1 and P2 strands the quest (the soft-lock above). | Greeting **C** for "stage 50 done, 60 not done" resumes at the hand-off. Debrief answers are stages 51–55; saying nothing is the default. |
| **A6** | MutualTrust +1 at the save (§9.2) *and* on Nell's first thanks (§8.2). | Counted twice, or once, depending on reading. And it stays after a later murder. | All outcome-based reputation and metric effects apply **once, at stage 50**, from the final state. |
| **A7** | Stage 50 requires stage 20. | A player who gets into town without touching the gate trigger skips the stage 40 failsafe. | Stage 50 runs stage 40 first if it has not happened. |
| **A9** | Greeting is keyed on holding the dispatch. | If the item is ever lost, no greeting fits. | Greeting and hand-over are keyed on **stage 20**. Removing the item is best effort; stage 20 is the proof it was earned. |
| **A10** | Nell can be killed anywhere before stage 50. | Killing her in the clinic, in front of the town, then hearing "no one to say how". | Caravan hands become **Essential once in town** (alias swap at stage 40). "No witness" can only follow a killing on the road. The witness is **either** surviving hand, not only Nell. |
| **A11** | The Cutters are "already in combat with the wagon crew", and Dunmore greets the player. | An actor in combat does not hold a conversation, and two Protected groups fighting each other never finish. | Stage the ambush as a **hold-up**: Cutters hold the hands at gunpoint, neutral to the player until attacked or until stage 37 (speech failed or deal refused). *Needs confirming in the game.* |
| **A12** | Stage fragments set objectives; scripts call `SetStage`. | Fragments are generated by the Creation Kit with hashed names and cannot be written or reviewed ahead of time. | **Stages are the API.** Anything that changes the quest sets a stage; the quest script's `OnStageSet` applies the effect. No fragments. Recovery is a function, because a stage fires once (`cqf TLM_MQ01 Recover`). |
| **A13** | The dispatch is a "specific placed reference" that the player loots from the marshal. | An item inside a corpse is not a placed reference. | Dispatch, journal and ledger are **Create Reference to Object — In** aliases (created inside the marshal or the lockbox when the quest starts). *Needs confirming in the Creation Kit.* |
| **A14** | The revolver alias is a Quest Object. | The player could never sell, drop or store their starting gun. | The revolver is not a Quest Object. The hint stage still fires on pickup. |
| **A24** | (Not considered.) Every event is treated as over before the next begins. | In the game it is not so. A death is announced about a second after it happens, and each handler runs on a thread of its own and gives others a turn at every call into the game. Found on 2026-11-12: (1) the player kills the Cutter lead, and the timer, the distance watch or the town stage arrives before the death is announced: the rescue is recorded as **Evaded**, the drover is killed and the wagon looted; (2) the town stage arrives while "evaded" is still being handled: the drover is put into the town alias, where he cannot be killed, and lives; (3) two resolutions at once can leave a mixture, or lose a betrayal. | Three guards in `TLM:MQ01Quest`, none of which changes a rule. A resolution that would be "evaded" asks first whether the lead is already dead; if so it is a rescue (`ResolveUnattended`). Only one first resolution may go ahead (`ClaimEncounter`). The town stage, and a betrayal that replaces an earlier outcome, wait until no other resolution is half done, never longer than five seconds (`WaitForResolutions`). |

Variants at the debrief are now a total function of the final state:

| Variant | When | Player choices |
|---|---|---|
| 1 Saved | outcome 1, Nell alive | none |
| 2 Evaded | outcome 2, Nell alive | admit / deny / say nothing |
| 3 Witness | outcome 3, a caravan hand alive | confess / blame the Cutters / "She's lying." / say nothing |
| 4 No witness | outcome 3, both hands dead | none |
| 5 Missed | outcome 4, Nell alive | none |
| 6 Lost | outcome 1, 2 or 4 and Nell died by a non-player cause | none |

Reputation at stage 50 is unchanged in spirit: +1 delivered, +1 Saved, −1 Exploited with a living witness. Range 0–2.

## SQ01 amendments

| ID | v0.1 said | Problem | v0.2 |
|---|---|---|---|
| **A8** | SQ01 starts when the ledger is picked up; clues examined earlier are counted then. | Alias scripts only receive events while their quest is running. A clue examined before the ledger is never recorded, and the journal's pickup event fires once, so E3 is lost for good. | SQ01 **runs silently from MQ01 stage 10** (stage 5, no objectives). Evidence is recorded as stages 11–14, in any order, before or after the ledger. |
| **A15** | Stage 15 "Evidence updated" is set each time a clue arrives. | A stage has no effect after the first time it is set. | Stage 15 is dropped. `RecomputeEvidence()` is a function; stage 20 (presentable) and new stage 25 (falsification established) each fire once. `Evidence` is split into `EvidenceCount` (0–4) and `EvidenceLevel` (0–2). |
| **A16** | Reporting is an option inside Pritchard's "has dispatch" greeting. | It disappears once the dispatch is delivered. | Reporting is its own Pritchard topic, available whenever SQ01 stage 20 is done and no outcome is set, before or after MQ01. |
| **A17** | "Destroy" records outcome 6. | No mechanism is given, and a Quest Object cannot be dropped. | A stove or fire activator with a confirm message. Owner may cut "destroy" instead (D5). |
| **A18** | Quest type "Miscellaneous/side". | Miscellaneous quests show no log text. | Type **Side**. |
| **A19** | If Haskell is dead, "use posted-no-name semantics". | Kept, and made explicit. | The Haskell button is hidden when he is dead (condition to add once he is placed); if it is pressed anyway the pages go up with no name. |

## Build approach (owner decision D7)

| ID | Change | Why |
|---|---|---|
| **A20** | The plugin's data records are generated from code ([tools/PluginBuilder](../../tools/PluginBuilder/), .NET 8 + the Mutagen library) instead of being clicked together in the Creation Kit. | An AI session can run commands on the game PC but cannot operate the Creation Kit window. Generated records are reproducible, reviewable in git, and keep stable FormIDs. The Creation Kit is still needed for the test cell, navmesh, actors' faces and dialogue, and is still the judge of whether the plugin is valid. |
| **A21** | Scripts live in the `TLM:` namespace (`scripts/Source/User/TLM/`), e.g. `TLM:MQ01Quest`, rather than `TLM_MQ01_QuestScript`. | Keeps the project's scripts in one folder in the game's `Scripts` directory. |
| **A22** | Every stage carries exactly one item (the Creation Kit's "log entry"), even a stage with no text for the player. In the file that means every stage's INDX is followed by a QSDT subrecord. | "Stages are the API" (A12) depends on `OnStageSet`, and the game sends that event per stage item. Seen in the game on 2026-11-12: with no items, stages were set and the scripts were never told. The builder's self-check and `tools/check_plugin_layout.py` enforce it. |
| **A23** | Nothing without a model is ever moved by script, and every record the scripts will place or move gets a model before it is used. | Seen in the game twice on 2026-11-12: `MoveTo` on a placed copy of this plugin's item, which has no model yet, never returned, and the script that called it stopped for good. The quest scripts move only actors today; the rule is for the placeholder items and for anything a later pass adds. |

## Test matrix changes

- **T10** splits: sneaking past *within sight* is Evaded; never entering the sight trigger is **Missed** (outcome 4).
- **T12** splits: killing Nell (the Cutters finish Abel) leaves no witness; killing only Abel leaves Nell as the witness; killing a hand after saving them is still Betrayal.
- **T14** splits: no Evaded while fighting; leaving mid-fight is Evaded; hiding until the timer expires is Evaded.
- **T19** adds: the hand-over works even if the dispatch has gone missing. (Corrected 2026-11-12: the logic model said the hand-over first sets the recovery stage, 900. Amendment A9 and the script never did; the model now agrees with them, and T19c checks that stage 900 is *not* set.)
- **T26** adds: the Pritchard conversation can be left and resumed; the gate trigger can be bypassed.
- **S18–S24** are new: journal before ledger, Haskell dead, Vane dead, ledger lost, report before and after MQ01, evidence frozen after an outcome. (Corrected 2026-11-12: the logic model said that deciding with a lost ledger gives the ledger back. The script never did; the decision stands without the item, and S21 now checks that.)
- Both corrections came from writing the in-game cases, which compare the whole of what can be seen with the model after every event; the older checks compared only the values a test happened to name.
- Engine-only cases the model cannot cover and that must be run in the game: **T13, T15, T16, T20, T22, T27, T28, S16**.

## Decisions needed from the owner

| ID | Question | What is implemented now |
|---|---|---|
| **D1** | Accept outcome **4 Missed** for a player who never meets the ambush? | Yes. Abel dies, Nell reaches town, Pritchard reports it without accusing anyone. |
| **D2** | Witness rule: v0.1 said Betrayal means Nell is dead. Should killing only Abel leave Nell alive as the witness? | Yes. To leave no witness the player must kill Nell themselves; the Cutters then finish Abel. |
| **D3** | Should Betrayal cost a hidden metric? v0.1 gives it none. | No cost. Only the debrief answer moves metrics. |
| **D4** | Player-facing text written for this build is provisional: stage 35 log ("You turned your gun on the wagon's own."), the three SQ01 log entries, both tutorial hints, the E2 observation, message titles and item names. | Marked provisional in `tools/PluginBuilder/Spec.cs`. |
| **D5** | Keep "destroy the ledger" with a stove activator, or cut it from the slice? | Kept, with a confirm message. |
| **D6** | Stage the ambush as a hold-up rather than a firefight (A11)? | Scripts assume a hold-up. |
| **D7** | Generate the plugin from code (A20)? | Yes for data records. The game loads the result (2026-11-12). Nothing generated has been loaded in the Creation Kit yet. |
| **D8** | Run the test matrix first with actors and markers made at run time by a test script, in the game's own test room, rather than waiting for a hand-built test cell (T2)? | A probe was written to find out whether it works at all (`TLM:FixtureProbe`, self-test scenario 2): it spawns the game's generic settler, forces it into the quest's aliases and kills it. **It works** (2026-11-12, VERIFY_LOG.md): the aliases hold the actors and the quest's scripts act on their deaths. Six full cases built this way, one for each way the encounter can end, **pass in the game** (self-test scenarios 4 to 9, 2026-11-12). So the rules that involve actors can be tested in the game without anyone operating the Creation Kit; what the player would see and walk through still needs a real cell. The whole matrix has since been carried this way: the 49 cases that need no built place, save or dialogue all pass in the game (2026-11-12). What is left of this decision is only whether that counts as the "logic proof" the plan asks for before a cell is built. |

Still open from v0.1: how a new game starts at the wreck (T1), whether to prove the logic in a test cell first (T2), whether an innocent should pay for the player's mistake in the opening hours (S-Q2), and the provisional minor names.
