# Act I revision: every node that changed

Companion to [the receipt](ACT1_CHARLES_REVISION_RECEIPT.md). Generated by comparing the story folder at the decision commit `4234ff2` with the revised folder, node by node. 196 changes.

How to read the Kind column:

- **SUPPLIED**: the new value is, character for character, a string in one of the two packets.
- **NAME**: the only difference is an approved surname or initial.
- **DATE**: the only difference is the year written as 2298.
- **SUBTRACTIVE**: words were taken out and none put in.
- **REMOVED**: the node is gone. For a stage's `.log`, the journal entry was blanked because the decisions contradict it and no replacement was supplied; new text is requested in the receipt.
- **WIRING**: a condition, a button's effect or link, a `reads` or `set_by` entry, or a node added to carry one. No story text was written for these; an added line reuses existing or supplied text.
- **DERIVED**: wording that is not in a packet. It is in a field no player reads, which describes mechanics or intent to a reader of the file, and it restates what the decisions or packets say. Each of these needs a second pair of eyes.
- **RECORD**: the file's own list of open questions, brought up to date.

Long values are cut short; the full text is in the files.
