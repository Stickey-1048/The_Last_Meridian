# Act I, packet 2: every node that changed

Companion to [the receipt](ACT1_CHARLES_PACKET2_RECEIPT.md). Generated by comparing the story folder at `975a262` (the same at `495de2a`) with the folder as revised, node by node. 136 changes.

Not in this table, because it applies to every line: each boxed line gained an `entry`, and some priorities changed. Those are in [the entry ledger](ACT1_CHARLES_PACKET2_ENTRY_LEDGER.md).

How to read the Kind column:

- **SUPPLIED**: the new value is, character for character, a string in one of the three packets.
- **SUPPLIED whole, inside a longer field**: a packet's rule or sentence stands entire inside a field that also holds other mechanics.
- **ADDED**: a new node. Its text is a packet's, or a copy of an existing line's for a context the format cannot put on one line.
- **WIRING**: conditions, a button's effect or link, a `reads` entry. A button label inside is supplied, already existing, or the builder's own word `Continue`.
- **DERIVED**: wording not in a packet, in a field no player reads, restating what the packets say. Each needs a second reader.
- **REMOVED**: gone.
- **RECORD**: the quest file's own list of open questions.

Long values are cut short; the full text is in the files.
