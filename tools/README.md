# Tools

Everything here supports building and checking the mod. None of it is the mod. The Windows scripts and the plugin builder first ran on the owner's PC on 2026-11-11 (results in [docs/design/VERIFY_LOG.md](../docs/design/VERIFY_LOG.md)). The game loaded the plugin and ran its scripts for the first time on 2026-11-12, and the self-test passed once a fault in the generated plugin was fixed: first one scripted scenario of stages and globals by hand, then 58 scenarios with nobody at the keyboard (1,456 checks, 0 failed), 49 of them the rows of the test matrices played with actors the test makes itself. Nothing has been opened in the Creation Kit, and nothing in a built place has been tested.

## Everyday use

```bash
tools/run_checks.sh                 # all checks that need no game
```

Change a rule in this order: `logic_model/tlm_model.py` and its tests, then `scripts/Source/User/TLM/*.psc`, then `PluginBuilder/Spec.cs`. `run_checks.sh` fails if the three drift apart.

`PluginBuilder/formkeys.txt` maps each EditorID to its FormID. Keep it in git: it is what stops a rebuild from renumbering records.

On the game PC, follow [docs/design/TEST_RUNBOOK.md](../docs/design/TEST_RUNBOOK.md).
